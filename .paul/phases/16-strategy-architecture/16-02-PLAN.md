<objective>
## Goal
Finish the instrument layer the 2026-08-31 probe started. Add `black_scholes_call` beside the
existing put. Add `SyntheticContract` and `OptionLeg` (price, delta, theta, a stable symbol) in
`strategies/instruments/options.py`. Add `RollCalendar` in `strategies/schedule.py`. Cover all
of it with offline tests. This is 12-01's AC-1 and AC-2, relocated by stage as Phase 16's
CONTEXT specifies.

## Purpose
16-03's three option rules need a leg object that can price itself, name itself (as a symbol the
`Book` can hold) and say when it expires. Without it every rule would re-derive Black-Scholes
inline — the "retyped model" failure the probe was written to prevent. The collar's short call
also needs a call pricer, which does not exist yet.

## Output
- `pricing.py` gains `black_scholes_call` and `black_scholes_delta` (put and call). The existing
  `black_scholes_put` is unchanged.
- New `instruments/options.py`: `SyntheticContract` base plus the `OptionLeg` dataclass.
- New `strategies/schedule.py`: `RollCalendar`.
- New `tests/test_option_instruments.py`.

**Deliberate deviation from Phase 16's sequencing:** 16-01 (the full stage skeleton — `observe`,
`constraints`, `sizing`, `orders`, `targets`) is NOT a prerequisite and is not built here. The
option work needs only `instruments/` (which exists) and `schedule.py`. The rest of the skeleton
stays with 16-01, whose value is the weight-native rules (16-04/16-05), not the option rules.
Decided with the user 2026-09-19.

## AC-1: The call pricer is exact and satisfies put-call parity
```gherkin
Given S=100, K=150, T=2.0, r=0.05, q=0, vol=0.20
When black_scholes_put and black_scholes_call are evaluated
Then put ≈ 38.0624 (12-01's worked example)
And put - call == pytest.approx(K*exp(-rT) - S*exp(-qT))   (parity, also with q=0.012)
And call >= max(S*exp(-qT) - K*exp(-rT), 0) with no clamp in the source
And the four 12-01 anchors still reproduce (IV 0.2098 / 0.1760, put 3.612 / 3.206)
```

## AC-2: OptionLeg prices, and its Greeks agree with finite differences
```gherkin
Given an OptionLeg(underlying="SPY", right="P"|"C", strike, expiry_bar, open_bar)
When price(spot, vol, tau), delta(...) and theta(...) are called
Then price() returns exactly what pricing.py returns for the same inputs (a thin wrapper)
And delta() matches a central finite difference of price() in spot to 1e-4
And theta() (per trading day) matches price(tau - 1/252) - price(tau) to 1e-3
And a put's delta lies in [-1, 0] and a call's in [0, 1]
And leg.symbol is a deterministic string unique per (underlying, right, strike, expiry_bar),
    e.g. "SPY P 625.94 @b63", usable as a Book symbol
```

## AC-3: RollCalendar counts bars, never dates

```gherkin
And year_fraction(63) == pytest.approx(0.25)
And schedule.py contains no timedelta and no calendar import
```

    - `black_scholes_call(spot, strike, tau, vol, rate=0.02, div_yield=0.0)`: same vectorised
      shape, the same degenerate-input guard and the same `_norm_cdf` as the put. The degenerate
      branch returns the discounted floor `max(S*e^-qT - K*e^-rT, 0)`. No clamp on the priced
      branch — the same reasoning as the put's AC-1 block, mirrored.
    - `black_scholes_delta(spot, strike, tau, vol, right, rate, div_yield)`: `e^-qT N(d1)` for a
      call, `e^-qT (N(d1) - 1)` for a put. Degenerate inputs return the step delta.
    - Factor d1/d2 into a private `_d1_d2` helper only if the put can call it without changing
      its outputs. Otherwise duplicate the two lines rather than touch the put.

    options.py (new, pure, no I/O):
    - `SyntheticContract`: a small base naming what every synthetic instrument must answer —
      `symbol` (str property) and `mark(spot, vol, tau) -> float`. Its docstring says why it
      exists: a synthetic contract is a KIND OF INSTRUMENT (CONTEXT.md "nouns by stage").
    - `OptionLeg(SyntheticContract)`, a frozen dataclass with fields `underlying`, `right`
      ("P"|"C"), `strike`, `open_bar`, `expiry_bar`. Methods:
      `tau(current_bar) = max(expiry_bar - current_bar, 0) / 252`, plus `price`, `delta`, `theta`
      (per trading day, as a one-bar price difference) and `intrinsic(spot)` (UNDISCOUNTED
      exercise value — what the leg settles at on its expiry bar). `mark` is an alias of `price`.
    - Vol reaches the leg ALREADY evaluated at its strike (12-01's constraint). The leg never
      calls synthetic_iv_surface itself.
    - Carry `rate` and `div_yield` as fields defaulting to 0.02 / 0.0, matching the probe. Add a
      comment that SPY's ~1.2% is a real value 16-03 may pass.
    - Comment style per CLAUDE.md (kts.py header block + a comment above each non-trivial line).
    Avoid: scipy, a `max(bs, K - S)` clamp, and any second implementation of the BS formula
    inside options.py.
