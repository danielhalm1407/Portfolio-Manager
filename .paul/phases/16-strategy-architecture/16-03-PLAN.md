<objective>
## Goal
Build `ProtectivePutRule`, `PutSpreadRule` and `RollingCollarRule` (with redeploy and funding) as
unit-native rules that `PortfolioSimulator` executes and accounts through the existing
`Book`/`Fill` path. Then show how each strategy's total value would have moved over the probe's
SPY window (2025-07-28 → 2026-07-24), next to unhedged SPY.

## Purpose
The probe priced single legs; it never ran a hedged book. This plan answers the user's question
directly — what would each structure have been worth, rolled every 63 bars, over the only window
we have? — and it makes the structures runnable for Phase 13. v1 surface throughout
(`base = 0.16`, `spot_ref` = the roll's start spot), so every payoff is a FLOOR (probe finding 6).

## Output
- An additive **synthetic-marks hook**: `RebalanceRule.synthetic_marks(ts, marks, book) -> {}`
  by default, and `PortfolioSimulator.run()` merges each rule's marks after `propose` and before
  execute
- `strategies/rules/options.py` with the three rules and a shared `OptionOverlayRule` base
- `tests/test_option_rules.py`
- `fig_overlay_values` in `option_probe_figures.py` (exported by `main()`), probe cell 10 and a
  write-up finding

**Decided with the user 2026-09-19 — overriding two 12-01 positions:**
1. *The simulator is extended*, although 12-01 listed `simulator.py` as DO-NOT-CHANGE. It has to
   be: `run()` marks and fills only from price-panel columns (`marks.get(sym)`, simulator.py:75),
   and a synthetic leg has no column, so no option trade could ever fill. The hook is
   strictly additive, and it is gated on byte-identical output from every existing caller.
2. *1 option per unit of underlying held* (no 100× multiplier, no 150% overhedge). Values stay in
   SPY price units, directly comparable to the probe. 12-01's open sizing question stays open for
   Phase 13.

**Known gap, stated rather than papered over:** 02-02 has not landed, so option Fills carry no
rationale. Each rule keeps its own `events` log (bar, action, symbol, qty, price, reason). When
02-02's channel lands, a later plan projects that log into `Order.rationale` — 12-01 AC-3's last
clause is deferred, not dropped.

    spread_width×S. `ValueError` if spread_width >= floor.
    `RollingCollarRule(floor=0.90, cap=1.28, redeploy_trigger=-0.05, redeploy_rate=1.0)`: long
    put, short call at cap×S. At each roll, after closing and before opening, apply 12-01's
    settle → redeploy / fund branch. Net cash = put close value − call close cost − the new pair's
    net premium, times the units hedged. Positive and period return ≤ trigger: buy
    `redeploy_rate × net / spot` more underlying ("collar redeploy"). Negative: sell `|net| / spot`
    underlying, capped at 0.999 × position ("collar funding"). Otherwise carry the cash, and state
    in a comment what "carried" means in a Book with no cash ledger. Keep 12-01's comment that the
    bse.py source settles at pure intrinsic, while here the premium is included.
