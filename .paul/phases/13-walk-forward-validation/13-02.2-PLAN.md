<objective>
## Goal
The fitted curves in 13-02.1 rest on six windows: three crises and three calm stretches. That is
too few. The 1-D fit at a fixed trigger is dominated by between-window spread (R² 0.09), the
trigger axis is sensitive to one or two extreme crisis cells, and the strike optimum sits on the
edge of the axis. This plan adds observations along four independent routes, ordered by cost and
risk. Each route can be approved or dropped on its own.

## Why the routes are separate
Each answers a different weakness, costs a different amount and carries a different kind of risk:

| Route | Weakness it answers | New simulation? | New data? | Main risk |
|---|---|---|---|---|
| A. Random windows on existing runs | too few observations to fit on | none | none | windows overlap, so they are not independent |
| B. Wider moneyness axis (down to 0.70×) | optimum on the 0.80 edge | yes | none | none beyond runtime |
| C. Longer SPY history (1990-2005) | too few regimes; no dot-com or 1998 | yes | VIX as proxy IV | VIX is not SPY's 63-day IV — basis must be calibrated |
| D. Growth underlyings (QQQ, then SMH) | portfolio is growth-tilted; index vol hides rotation | yes | QQQ none; SMH IV probe | semis have no vol index before IBKR coverage |
</objective>

<routes>

## Route A — random windows over the existing runs (no new simulation)

**Method.** Draw window start dates uniformly over 2006-01 → 2026-09. Draw lengths from
{42, 63, 126, 252, 504} bars. Score every one of the 63 persisted configurations on each window by
slicing, exactly as the six indicative windows are scored now. Label each window from SPY's own path:
*drawdown* if SPY's MDD ≥ 10% inside it, *calm* if SPY's MDD < 5% and its return > 0, *mixed*
otherwise. The six named windows stay as the narrative set. The random set feeds only the fitting
step and the per-trigger robustness table.

**The catch, stated up front.** Random windows overlap, so 500 windows are nowhere near 500
independent observations. Two mitigations: (1) a non-overlapping variant (one window per block of
the history), reported beside the overlapping one; (2) fits on window-demeaned scores, as the pooled
surface already does. The effective sample size is reported, not just the count.

**Micro-recent windows** fall out of the same sampler at the short lengths, plus a few named ones:
the August 2024 carry unwind, the April 2025 tariff shock, and January 2025 (DeepSeek) for the
Nasdaq and semiconductor routes. Short windows are shorter than one roll, so they measure
the mark-to-market of a hedge already in place, not the full roll cycle. That is said beside them.

**Compute.** No simulation. One score is a slice plus a running max: about 1-3 ms in pandas. With
63 configurations × 500 windows = 31,500 scores, that is **about 1 minute**. Fitting is seconds.

## Route B — extend the moneyness axis below 0.80×

**Method.** Add 0.700, 0.725, 0.750, 0.775 to the strike axis: 13 strikes × 7 triggers = 91
configurations. Only the 28 new ones need simulating; the 63 existing runs are reused.

**Compute.** Measured: 3.6 s per full-history run (5,201 bars, about 0.7 ms per bar, linear since
13-01.1's narrow ledger). 28 new runs × 3.6 s ≈ **1.7 minutes**.

**Watch for.** Below 0.75× the budget buys 25+ contracts per unit. Premiums that small are the most
exposed to the missing bid/ask spread, so a transaction-cost sensitivity row is added at this step,
not later.

## Route C — SPY history back to 1990, with VIX as proxy implied vol

**Data.** yfinance: ^VIX daily from 1990-01-02; SPY from 1993-01-29 (^GSPC before that, price
only; the dividend yield is already a constant in the pricer). A new
`src/pipelines/cache_iv_proxy.py` writes `data/processed/iv_proxy_long_history.parquet`. `data/raw/`
stays append-only.

**Calibration, the step that decides whether this route is usable.** VIX is the 30-day implied vol
of the SPX option strip. The rule prices off IBKR's SPY implied vol. On the 2006-2026 overlap, fit
`iv_ibkr = a + b · VIX` (plus a check of the residual by regime), and apply it before 2006. Stitch
at 2006-01-09, with provenance recorded per bar. If the residual is regime-dependent (likely higher
in crises), use the regime-specific fit, and say so. **Exit criterion:** if the calibrated proxy
misprices a 0.90× put by more than 15% on the overlap, stop this route rather than publish
numbers on it.

**What it adds.** 1990 recession, 1997 Asian crisis, 1998 LTCM, 2000-02 dot-com bust, 2001, and
the 2003 recovery as a calm stretch. That gives five or more extra named windows and, through Route
A, about 75% more history for random windows.

**Compute.** About 9,250 bars per run × 0.7 ms ≈ 6.5 s per run. 91 configurations ≈ **10 minutes**.
Data pull plus calibration: under a minute of network and seconds of fitting.

## Route D — growth underlyings: QQQ first, then semiconductors

**Why.** The portfolio is growth-tilted. The broad index can show less volatility and shallower
drawdowns than what a growth book actually experiences, because rotation within and across sectors
nets out at the index level. Hedging the thing the book actually holds is a different question,
and moneyness may answer it differently.

**QQQ — no new data needed.** QQQ prices from 1999 and IBKR QQQ implied vol from 2006 are already
in `data/processed/` (measured mean IV 0.203 against SPY's 0.166). It needs one parameter
(`underlying`) threaded through `run_config` and the loaders. Optional extension back to 2001 with
^VXN, calibrated as in Route C, which brings in the dot-com bust (QQQ fell ~83%).
Compute: about 6,900 bars (1999+) or 5,200 (2006+) × 0.7 ms ≈ 3.6-4.8 s per run. 91 configurations
≈ **6-7 minutes**.

**Semiconductors (SMH or SOXX) — data probe first.** There is no vol index for semis. Step one is
an IBKR `OPTION_IMPLIED_VOLATILITY` probe for SMH and SOXX, the same probe 11-01 ran for SPY/QQQ.
If coverage starts around 2006-2010, use it as is. Before that, a realised-vol proxy scaled by the
fitted IV/RV ratio from the overlap is possible but weaker, so it would be flagged as such or
skipped. Compute: similar to QQQ, **about 6 minutes** once data exists.

**Comparison output.** The same score grid with an underlying axis: is the moneyness optimum
deeper on a higher-vol underlying, and does the trigger regime-split persist?
