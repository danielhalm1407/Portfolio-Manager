<objective>
## Goal

Verify the built execution stack against a live TWS session, in a fixed order, with each stage gated
on the one before it — ending in an approved live rebalance and a post-trade position snapshot.

## Purpose

Everything in phases 4-6 was tested offline against stubbed callbacks. That proves the logic, not the
integration. `reqExecutions`, `check_existing_port.py` and the live submit path have never executed
against a real gateway. Until they do, the execution half is built but unproven.

## Output

No new source files. The artefacts are run records: a dry-run diagnostic table, an order verdict
table, and before/after position logs.
</objective>
